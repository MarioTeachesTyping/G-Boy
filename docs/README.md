# `docs/` — Documentation

| File | What it is |
|---|---|
| [`SPEC.md`](SPEC.md) | The project spec and roadmap: goals and non-goals, a GBA hardware summary and memory map, the core/frontend architecture, the milestone plan (M0–M8) with "done when" criteria, the testing strategy, the BIOS policy, build instructions, the code style rules, and the list of known simplifications. |

The spec is the source of truth for **what we're building and in what order**. The per-folder
`README.md` files across the repo explain **what currently exists** in each folder and how it works.
When a milestone lands, update the status line and milestone table in `SPEC.md`, plus the README of
any folder whose contents changed.
